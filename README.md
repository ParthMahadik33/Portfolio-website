# Parth Mahadik — Personal Portfolio

An editorial personal portfolio hero for Parth Mahadik, Software Developer & Computer Engineering Student, combining modern high-contrast typography with understated Maharashtrian heritage artwork.

## ✨ Features

- **Editorial Typography**: Bodoni Moda display serif, Barlow Condensed uppercase roles & navigation, and Martel stone-heritage Devanagari calligraphy (`उद्यमेन`).
- **Authentic Art Direction**: Original foreground portrait layered over a transparent Sahyadri fort landscape, distressed vermilion red sun, flying bird silhouettes, and subtle paper grain overlay.
- **Coordinated Motion**: Orchestrated entrance animations using Motion for React / Framer Motion with complete `prefers-reduced-motion` accessibility support.
- **Responsive Architecture**: Edge-to-edge layout calibrated for ultra-wide, desktop, tablet, and mobile displays without horizontal overflow or clipped typography.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: SCSS Modules & Global SCSS tokens
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Typography**: Google Fonts (Bodoni Moda, Barlow Condensed, Martel, Inter)

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn

### Installation

```bash
git clone https://github.com/ParthMahadik33/Portfolio-website.git
cd Portfolio-website
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
npm run build
npm start
```
